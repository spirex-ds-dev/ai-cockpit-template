# Installation Documentation Maintenance

This is a maintainer checklist, not part of the installation path.

- Keep English, Chinese, and Japanese home pages semantically aligned.
- Keep the home path thin: map, prerequisites, six steps, completion, and links.
- Put supply-chain evidence, recovery, internal models, and maintenance detail in their dedicated routes.
- Check that tables render, internal links resolve, and iOS/Android/Java routes remain available.
- Keep instructions version-neutral; resolve the release during verified installation.
- Preserve the no-guess, no-overwrite, no-silent-fallback, and separate-approval boundaries.
- Run the documentation metadata tests before merging.
