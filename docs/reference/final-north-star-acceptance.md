# Final North Star acceptance

The final decision is `GO`, `CONDITIONAL_GO`, or `NO_GO`. It is derived from
named evidence dimensions, never an agent's assertion. `GO` additionally
requires current verified real-adopter and provider evidence. Repository-local
tests, fixtures, archived records, and policy checks cannot substitute for
those external facts; absent external evidence requires an explicit limitation
and prevents `GO`.

The evaluator requires all twenty acceptance dimensions and preserves the
limitations for human review. It does not publish releases, configure providers,
or schedule Work Items.
