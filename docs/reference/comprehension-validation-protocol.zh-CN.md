# P0 文档读者理解度验证协议

这是研究协议，不是理解度结果。它用于在英文、简体中文和日文 P0 路径完成修订后，向独立读者发起受控验证。

## 参与条件与隐私

- 参与者不能是 AI Cockpit 项目成员，并应能阅读所选语言。
- 优先选择没有软件开发背景的读者；只记录匿名参与者代号。
- 不收集姓名、联系方式、雇主、精确位置或其他可识别信息。
- 明确说明参与自愿，回答只用于汇总后的文档证据。

## 固定阅读路径

1. 只提供所选语言的根 README 和文档入口。
2. 请读者依次阅读目的、思想、架构、能力边界、决定状态、首次校准、首个 Work Item 和恢复文档。
3. 阅读过程中不要解释术语、纠正读者或指向其他语言。
4. 提问前记录确切文档版本和语言。

## 六个问题

1. 请用自己的话说明这个项目解决什么问题。
2. 项目的 North Star 是什么？在实际工作中意味着什么？
3. AI Cockpit 控制什么？哪些责任仍属于人或外部工具？
4. 什么情况下会继续、调查或停止？
5. 采用项目并开始首个 Work Item 时，第一步会做什么？
6. 如果必需检查或证据缺失，会做什么？不会做什么？

## 评分与证据边界

每个回答只能标为 `correct`、`partially_correct`、`incorrect` 或 `no_answer`，并记录支持评分的原话或转述。必须使用[回答记录 schema](comprehension-validation-response.schema.json)。静态测试、Agent 自评、链接检查或页面数量比较都不是读者证据。收到并审核最低样本量的原始回答前，状态保持 `comprehension_unverified`。
