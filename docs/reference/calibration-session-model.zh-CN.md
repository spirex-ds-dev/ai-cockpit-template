# 校准内部模型

这是维护者和审计者参考，不是安装教程。

校准 Runtime 会保存可恢复的 Session、回答与证据、校对清单证据、阶段记录和可审核的提议。
它保留 Unknown，不会编造事实。提议不等于已启用的策略：启用仍然要求独立的人工确认和当前证据。

详细运行时字段、陈旧证据规则、确认边界和当前实现状态见
[Calibration Session](calibration-session.md)及[能力事实矩阵](capability-truth-matrix.md)。
Work Item 记录理由、验收、负责人决定和外部验证链接；它不替代保存的校准事实，也不能证明人的身份。
