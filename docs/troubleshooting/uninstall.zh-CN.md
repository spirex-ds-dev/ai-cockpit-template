# 卸载 AI Cockpit

仅在工程负责人决定移除已安装 Runtime 时使用本恢复路径。不得凭猜测删除文件。

1. 只读取工程并记录存在的 AI Cockpit 文件。
2. 请负责人确认记录应保留还是清除。
3. 生成移除计划，但不要写入。
4. 审核计划、受影响文件、缺失事实和恢复方法。
5. 执行前取得独立确认。
6. 只执行已批准的计划，不得删除无关工程工作。
7. 验证移除回执并保留证据。

所有权、范围或恢复方式为 Unknown 时，停止并联系仓库负责人。
