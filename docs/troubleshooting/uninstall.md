# Remove AI Cockpit

Use this recovery route only when the project owner has decided to remove the
installed Runtime. Do not delete files by guesswork.

1. Read the project and record which AI Cockpit files are present.
2. Ask the owner to confirm whether records must be preserved or purged.
3. Generate a removal plan; do not write yet.
4. Review the plan, affected files, missing facts, and recovery path.
5. Obtain a separate confirmation before execution.
6. Execute only the approved plan, without deleting unrelated project work.
7. Verify the removal receipt and retain the evidence.

If ownership, scope, or recovery is Unknown, stop and contact the repository owner.
