# Post-archive hosted functional recovery plan

1. Add a red regression using a completed failed pull-request pytest log with
   node IDs and a pytest failed-test summary.
2. Inspect the existing receipt validator and implement the smallest
   classifier extension that preserves provider and archive bindings.
3. Add or update negative tests for arbitrary logs and invalid provider
   identity/state.
4. Document the accepted evidence shape and its limits in the lifecycle
   reference.
5. Run focused tests, required governance checks, quality verification, then
   archive, review, merge, close, and clean up through the normal lifecycle.
