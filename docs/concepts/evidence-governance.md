# Evidence Governance

AI Cockpit follows one chain:

```text
Evidence → Governance Decision → Human Control
```

Native governance evidence includes Intent, Contract, verification execution,
Summary, Cockpit Status, Outcome, and archive records. Delegated domain evidence
includes test results, coverage, scans, SBOMs, provenance, signatures, and
provider review evidence produced by their specialist tools.

Agent prose is never sufficient proof by itself. Evidence must identify a
reviewable command, exit code, result, path, commit, hosted run, provider record,
or human decision. When proof is absent, record `unknown`, `not_run`,
`not_proven`, `evidence_gap`, or `needs_human_confirmation`.
