# Trust Layer

AI Cockpit supports calibrated human-agent trust by turning repository evidence
into bounded governance decisions. Trust increases only when the cited evidence
supports it; missing, stale, contradictory, or insufficient evidence returns
control to a human.

The product boundary is a **Repository Governance Layer**. It is not an Agent
Runtime, Workflow Engine, Security Sandbox, identity provider, compliance
certificate, or substitute for human review.
